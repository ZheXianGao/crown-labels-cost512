# 512版树冠标签生成：流程与伪代码

这份说明按当前代码的执行顺序写。主流程在 [`worker.py::run()`](../crown_labels/worker.py)，具体建模在 [`science.py`](../crown_labels/science.py)。以下伪代码省略文件读写、缓存和日志，保留会影响标签的判断。

## 1. 先看完整流程

```text
输入：原始LiDAR点云、DTM、DOM、窗口范围
      可选的农田/电线等地理质检掩膜

points, treetops = 准备点云与树顶()
graph           = 在三维体素节点之间建图(points)
candidates      = 构建单冠高斯、双冠和层级多冠假设(points, treetops, graph)
unary           = 计算各节点属于各候选及背景的代价(candidates)
voxel_labels    = 联合优化(unary, graph, 实例代价=512)
cleaned_labels  = 三维清理(voxel_labels)
instance_image  = 按每格最高原始回波投影(cleaned_labels)
instance_image  = 应用地理质检并整理二维轮廓(instance_image)

输出：完整instance_ids、RGB有效域、dense前景/背景、高度及高度可靠域
随后：按固定地理范围构建512训练裁块，RGB放大至1008送入模型
```

RGB不用于判断高斯候选属于哪棵树。DOM提供有效影像范围和最终配准的RGB；点云几何、离地高度及邻接关系决定三维分冠。

## 2. 点云准备与树顶候选

对应 [`prepare.py`](../crown_labels/prepare.py)、[`core/peaks.py`](../crown_labels/core/peaks.py)、[`core/admission.py`](../crown_labels/core/admission.py)。

### 2.1 高度归一化与一次体素化

```text
对每个原始回波 p=(X,Y,Z)：
    ground_z = 在DTM自身网格上双线性插值得到地面高程
    h = Z - ground_z

    若高度非有限，或 h≤0.5m，或 h>60m，或不在有效范围：
        不作为植被建模节点

将保留点按 (局部x, 局部y, h) 分入0.1m×0.1m×0.1m体素

对每个非空体素 i：
    节点位置 v_i = 体素内局部x、局部y、相对原始Z的均值
    离地高度 h_i = 体素内归一化高度h的均值
    代表回波 = 体素内归一化高度最高的真实回波
    local_support_i = 0.8m三维邻域内的支持节点数（最多查询16个）

另在0.1m二维格网上记录：
    upper[r,c] = 该格原始回波的最高离地高度
    count[r,c] = 该格原始回波数量
    top_voxel[r,c] = 最高原始Z回波所属的体素编号，无合格体素则为-1
```

节点用于建图的第三维是原始Z减去全窗同一个常数后的均值；`h_i`另存。两者在有地形起伏时不能互换。DTM按自身分辨率插值，并不要求DTM也有0.1m的独立地面观测。

### 2.2 从真实点找树顶，不从插值CHM找峰

```text
输入体素代表回波中高度≥2.5m的点
按高度降序做0.5m短名单抑制，减少重复检查

对短名单中的每个点 p：
    邻域 = 平面距离≤2.0m的点
    若邻域有比p更高超过1e-5m的点：跳过

    顶部支持 = 距p≤0.35m且高度≥p.height-0.5m的点数
    若顶部支持<3：跳过

    取1.08～1.8m环带，按方位分成12个扇区
    每个至少有3个点的扇区，取高度95百分位
    若可用扇区不足6个：跳过

    prominence = p.height - 各扇区顶部高度的35百分位
    若 prominence<0.3m：跳过

对通过点按高度降序保留，任意两个保留树顶距离至少2.0m

再对每个树顶检查2.0m平面邻域的三维形状：
    ratio = sqrt(Var(h) / max((Var(x)+Var(y))/2, 1e-12))
    只保留 ratio≥0.7 的候选
```

这里的2m是邻域半径/树顶间距参数，不能解释成“只保留直径4m以上的树”。没有合格树顶时保留背景结果，不补造种子。

## 3. 三维建图

对应 [`core/algorithm.py::make_graph()`](../crown_labels/core/algorithm.py) 和 [`science.py::build()`](../crown_labels/science.py)。

### 3.1 邻接关系

```text
输入：三维体素节点位置 v_1,...,v_N
建立三维KD树

对每个节点 i：
    在0.8m内查询最近至多12个其它节点
    对每个找到的节点 j：
        加入无向边 {i,j}

将重复的无向边合并
每条边分别存 i→j 和 j→i，保证邻接矩阵对称
图的边长度 d_ij = ||v_i-v_j||_2
```

这是“半径约束的近邻图”，不是0.8m内所有点两两连接，也不是二维像素四邻域。对称化后，一个节点的实际度数可能超过12。

### 3.2 同一图有两种用途

```text
三维路径支持：
    使用边长 d_ij 做Dijkstra最短路径
    判断节点能否沿真实三维邻接路径连接到树顶核心

优化中的平滑项：
    每条无向边只计一次
    w_ij = 1.5 × exp[-0.5 × (d_ij / 0.45m)^2]
    若相邻节点被分给不同实例，支付 w_ij
```

边长较短的节点更倾向同属一个实例，但平滑项不会单独决定实例归属，仍需与数据代价和实例代价竞争。

## 4. 单冠高斯与联合候选

对应 [`core/builder.py`](../crown_labels/core/builder.py)、[`core/joint_model.py::gaussian_model()`](../crown_labels/core/joint_model.py)、[`core/proposals.py`](../crown_labels/core/proposals.py)。生产入口使用同内容的锁定构建核 `builder_kernel.py.txt`。

### 4.1 为每个树顶选核心与拟合样本

```text
upper_context = 对upper做2×2最大值滤波
                 # 仅用于当前可见性/局部背景计算，不重新检测树顶

对每个树顶 s：
    core = 平面距树顶≤0.6m的节点
    core只保留：
        h_i>0.5m
        h_i≥所在格upper_context-0.6m
        local_support_i≥3

    若core节点数<6，或core高度95百分位≤2.5m：跳过此候选

    fit = 平面距树顶≤2.0m、h_i>0.5m、local_support_i≥3的节点
    distance = 从core在三维图上出发的最短路径，最长5.0m
    fit只保留distance有限的节点
    若fit节点数<6：跳过此候选

    保存单冠候选：核心core、拟合样本fit、树顶来源编号
```

拟合使用核心周围有三维支持的植被，不只拟合最顶部那一薄层；否则高斯会缩在冠顶，难以覆盖较低的冠缘。

### 4.2 稳健三维高斯拟合

```text
输入：候选的拟合节点集合 X

μ = X在x、y、z三个坐标上分别取中位数
δ_i = X_i - μ
cap = max(所有||δ_i||的90百分位, 0.35m)

将过远的偏差向量径向压到cap以内：
    δ'_i = δ_i × min(1, cap / max(||δ_i||, 1e-8))

Σ = Σ_i(δ'_i δ'_i^T) / N
Σ = 0.9Σ + 0.1 × trace(Σ)/3 × I

对Σ做特征分解，把特征值限制在[0.35², 8.0²]m²
重建Σ，计算Σ⁻¹及log|Σ|
```

中心是逐坐标中位数，协方差还做了离群抑制、收缩和特征值限幅；不是对原始样本直接做一次普通协方差拟合。

### 4.3 高斯数据代价与可达范围

```text
对候选k与节点i：
    m² = (v_i-μ_k)^T Σ_k⁻¹(v_i-μ_k)

    初始可行条件：
        节点在候选搜索半径内
        m²≤16
        到候选fit集合最近距离≤5m

    可行时：U_raw(i,k)=0.5m²+0.5log|Σ_k|
    不可行时：U_raw(i,k)=∞

再用core出发、长度≤5m的三维图路径约束：
    路径不可达：即使高斯允许，也改为∞
    路径可达但高斯未覆盖：补充成本1+0.15×路径长度

对每个节点，以当前所有前景候选中最小有限成本为基准：
    U(i,k)=clip((U_raw(i,k)-min_foreground_cost_i)/8, 0, 1)
```

候选搜索半径为 `min(24m, sqrt(最大协方差特征值×16))`。高斯是空间先验，并非不可跨越的椭球边界；观测图上的短路径允许一定冠缘延伸，但不会通过二维膨胀跨过没有三维支持的区域。

### 4.4 双冠与层级多冠假设

```text
双冠候选：
    对单冠a、b，若树顶距离≤10m：
        比较两者core的5m图路径可达集合
        若共有可达节点≥6：记录联合假设
    按可达集合重叠比例优先、树顶距离次优排序，最多保留300个双冠假设

多冠候选（至少3个树顶）：
    对现有图边，定义高度权重 min(h_i,h_j)
    由最大生成森林按高度从高到低合并连通分量
    记录含树顶的分量相遇时的完整树顶集合
    只保留：最大树顶间距≤10m、所有成员共有有限支持节点≥6的集合
    已存在的成员组合不重复添加
```

最大生成森林在代码中通过“负高度权重的最小生成树”实现。它用的是已有三维图，不重新添加树顶，也不直接决定最终合并。

联合候选的有效数据项采用子单冠成本的等权混合：

```text
对子候选集合S：
    U_joint(i) = -log[ Σ_{k∈S} exp(-8U(i,k)) / |S| ] / 8
```

不是取各子冠成本的最小值，也不是只用一个大椭球的成本。联合候选会保存高斯几何记录，但优化使用上面的子候选混合成本。

### 4.5 背景竞争与局部高度惩罚

```text
背景标签编号固定为0：U(i,0)=0.8，背景激活代价为0

双冠成本替换为子候选混合后，再减去每节点的最小有限前景成本

构造局部背景高度B：
    对upper做当前2×2最大值滤波
    对观测缺口用最近的有效观测补齐，仅供背景基准计算
    在101×101格（约10.1m宽）的窗口取高度20百分位

对节点i：
    excess_i = h_i - B(节点所在格)
    penalty_i = 0.8 × max(0.6 / max(excess_i,0.05) - 1, 0)
    所有有限前景成本都加上penalty_i

最后添加层级多冠候选，其混合成本由此时的子单冠成本计算
```

这个高度项衡量相对局部低层基准的突出程度，并不等同于“离地超过某个阈值就是树”。背景编号0是优化中的必要竞争状态；最终有效区域内仍是前景/背景dense监督，没有第三类unknown。

## 5. 联合优化：三项能量

对应 [`core/family_solver.py`](../crown_labels/core/family_solver.py)、[`core/hierarchy.py`](../crown_labels/core/hierarchy.py)、[`core/joint_solver.py`](../crown_labels/core/joint_solver.py)。

每个体素只能取一个标签：背景0，或一个单冠/联合候选编号。目标为：

$$
E(L)=\sum_i U(i,L_i)
+\sum_{\{i,j\}\in\mathcal E}w_{ij}[L_i\ne L_j]
+512\sum_{k>0}[\exists i:L_i=k].
$$

最后一项是**每启用一个前景实例付一次512**，不是每个体素付512，也不是SAM3训练损失权重。它抑制不必要的实例数量。

### 5.1 从单冠开始，允许细化、合并与拆分

```text
初始化：
    每个节点只在背景和单冠候选中选成本最低者
    双冠/多冠候选不作为初始化标签

建立父子关系：联合候选的成员是对应单冠候选
约束：
    同一联合候选与其子单冠不能同时活跃
    两个共享子单冠的联合候选不能同时活跃

每轮按固定顺序尝试：
    refine(单冠)：允许该单冠调整归属
    merge(父候选)：允许联合解释替换成员单冠及冲突父候选
    split(活跃父候选)：允许其子单冠替换联合解释

对每个动作：
    ROI = 受影响候选的有限支持集合
          ∪ 当前属于待移除候选的节点
    allowed = 背景 ∪ ROI当前标签 ∪ 此动作加入的候选 - 待移除候选
    在保持ROI外标签固定的条件下求解ROI

    若新解满足父子互斥，且完整能量下降超过1e-6：接受
    否则保留旧标签
```

合并动作不只删除直接成员，还处理共享成员的冲突父候选，并恢复冲突父候选中不属于本次合并的其它子冠。当前实现允许节点在背景与不同树冠之间竞争，不是先把每个树顶周围硬切成一棵树。

### 5.2 ROI子问题不忽略边界和实例激活成本

```text
构造ROI子问题：
    保留ROI内部边的Potts项
    对ROI与外部的边，把外部固定标签带来的代价加到ROI数据项
    若某候选在ROI外已有节点，则其激活代价在该子问题中记0
        # 避免局部求解重复支付已在全局支付过的512
    其它候选仍保留相应激活代价
```

### 5.3 内层α-expansion与最小割

```text
内层每一轮：
    按有限支持节点数降序遍历前景标签，最后尝试背景0

    对当前目标标签α：
        只让“当前不属于α、且α成本有限”的节点参与
        每个参与节点做二选一：保持当前标签 / 改成α

        建立二元图：
            数据项 → 源/汇边
            Potts平滑项 → 节点之间的边
            实例启用/停用代价 → 辅助节点及约束边

        容量按至多10000倍缩放成整数，必要时降低倍数以避免溢出
        用SciPy maximum_flow(method="dinic")求最小割
        将割结果映射回标签提案

        重新计算浮点三项能量
        只有下降超过1e-7才接受该α动作

    整轮没有接受动作，且没有超时：内层停止
```

图割解的是当前二元移动，不是一次求出整个多标签问题的全局最优解。整数容量产生的提案最终还要通过浮点能量检查。

### 5.4 停止与导出条件

```text
每个ROI内层：最多50轮、60秒
每次外层调用：最多30轮、3600秒
若尚未完成，可带着当前解续算，最多30次外层调用

只有一次完整外层遍历满足：
    没有被接受的动作
    所有内层子问题均完成
才标记 converged_full_pass=True

最终仍未达到完整遍历收敛：不导出训练标签
```

停止条件表示“当前规定动作集合下没有进一步下降”，不证明全局最优。求解中只有完全相同且已收敛的数值子问题才可复用缓存。

## 6. 三维清理、最高回波投影和二维整理

```text
对每个活跃实例：
    在该实例的三维子图上找连通分量
    保留：分量至少6个体素，且在全图上距该实例核心有≤8m的路径支持
    对保留部分检查：离地高度q95>2.5m，平面最大Feret宽度≥1.5m
    不合格实例改为背景

对每个0.1m平面格：
    找到该格原始Z最高的真实回波
    若它对应一个合格植被体素：投影这个体素的实例ID
    否则为0，不再向下找其它回波替代

按外部地理质检掩膜移除指定区域/指定整冠
    这些掩膜来自额外质检，不是高斯算法自行识别农田或电线

按现有顺序：
    小间隙修补 → 轻度轮廓整理 → compact轮廓整理 → surface收尾
    间隙修补和surface填孔不覆盖其它实例
    两轮轮廓整理可调整实例间的边界归属，但保护冠体核心并限制变化
    不跨越规定的禁入区域，不凭空生成新ID
```

间隙修补默认闭运算半径0.3m、孔洞上限1m²、最大补点距离0.4m，每个实例最多补原面积30%。轮廓整理有两组固定配置：

| 参数 | 轻度整理 | compact整理 |
|---|---:|---:|
| 高斯平滑σ | 0.15m | 0.30m |
| 开运算 | 0.10m | 0.20m |
| 闭运算 | 0.20m | 0.40m |
| 最大扩张距离 | 0.20m | 0.40m |
| 小岛面积参数 | 0.08m² | 0.20m² |
| 孔洞面积参数 | 0.08m² | 0.80m² |
| 最大变化比例 | 0.10 | 0.30 |

轮廓整理的关键不是对每棵树各自膨胀后直接叠加，而是带保护和回退的像素竞争：

```text
对每个实例：
    提出删除微小分离片的候选
    开运算半径=min(配置半径, 0.2×该实例等效半径)
    再闭运算、填允许的小孔，计算高斯平滑后的轮廓得分

每个像素暂分给得分最高且超过0.5的实例
将原实例内部深度>0.6m的像素及其最深锚点恢复为原ID
原归属得分与最优得分差小于1e-6时，优先保持原归属

逐实例检查：
    实例消失 / 改变像素数超过预算 / 连通分量变多
    若发生任一情况：回退该实例相关变化
重复检查回退影响，直到稳定
```

因此，轮廓整理可以缩小、扩张或重分配冠缘；不能描述为“所有原有前景像素都不动”。

最后的surface收尾只补封闭、未占用、面积≤1m²且离冠体≤0.4m的孔；移除≤0.2m²的微小分离片，保留最大分量及触及处理窗边界的部分。完整处理窗清理后再切核心与训练块，不在每个训练块中重新分冠。

## 7. 高度辅助目标和训练数据另行导出

```text
每个0.1m格：
    若RGB有效、地面观测支持有效、回波数≥3、upper有限且在[-2,60]m内，
    并且未落入地理排除区：
        H=True
        height=max(upper,0)
    否则：H=False，height=NaN

H不由实例前景决定；背景格也可能有可靠高度
缺失高度不插值填成0

训练裁块：
    保留与裁块相交的完整实例，不按实例质心删除伸入裁块的部分
    GDAL将DOM采到0.1m、512×512，对应51.2×51.2m
    dense有效域内：ID>0为实例前景，ID=0为背景；无效域不计分割损失
    默认另扣8像素工程边缘
    高度及H保持独立
    RGB双线性放大至1008×1008；实例ID不做双线性插值
```

这里的高度规则指当前新生成器。复现历史paired640时，使用模板原样保留RGB、有效域、高度和H，只替换实例标签；不能把模板中的历史高度目标称为重新按0.1m生成的高度。

训练裁块的512像素与实例代价512没有数学联系。1024核心通常切4个不重叠512块；历史640由128母窗各5个重叠位置组成，必须按模板复现，不能把640个裁块当作640个独立样地。
